# Changelog

## 1.0.0

First release.

- Course catalogue on the course index page: search, filters from categories, tags and course custom fields with
  faceted counts, quick filters, date range, sorting, grid and list views, pagination and a course quick view.
- Catalogue editing in place: filter layout by drag and drop, course card content, optional features and options,
  with live preview.
- Home page builder with templates and configurable sections.
- Footer builder with columns of blocks.
- Page margins for the site, the home page and the catalogue, adjusted in place.
- Appearance settings: colours, fonts, corner radius, shadows, login background, breadcrumbs, raw SCSS.
- Privacy API provider for the catalogue user preferences.
